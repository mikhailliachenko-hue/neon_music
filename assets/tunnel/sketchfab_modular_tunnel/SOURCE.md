# Modular Tunnel

- Creator: Just8
- Source: https://sketchfab.com/3d-models/modular-tunnel-579fd8ff94584cf1ad3ccb1a3e8cbb99
- Downloaded format: GLB with 1K textures
- Imported: 2026-08-24
- License: Creative Commons Attribution 4.0

The original model is kept unmodified. Runtime palette and emission overrides
are applied by the existing Godot tunnel material pipeline.

`solar_portal_arch.tscn` keeps only the large entrance arch. The raw multi-part
GLB is disabled in Asset Registry metadata so its distant kit pieces cannot be
selected by automatic layouts.
